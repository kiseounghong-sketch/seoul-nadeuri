2026학년도 2학기 서울 현장체험학습(11. 19.~20.) 학생용 안내 웹앱입니다.

- 주소: https://seoul-nadeuri.web.app
- `main`에 올리면 GitHub Actions가 Firebase Hosting에 자동으로 올립니다.
- 내용 수정: `public/index.html`의 `DAYS`(일정), `RULES`(지킬 것), `PACK`(준비물), `MUSEUM`(박물관), `WORK`(활동지 질문), `LUNCH`(1일차 점심 메뉴) 부분
- 점심: 학생은 ‘지금 → 점심’에서 매운 음식 가능 여부를 먼저 고르고 메뉴를 골라요(못 먹으면 매운 메뉴는 못 고름). 선생님 앱 ‘활동지 → 점심’에 메뉴별 인원이 모여요. `LUNCH.until`부터는 바꿀 수 없어요.
- 활동지 탭은 11. 19. 09:00(출발)부터 준비물 탭 자리에 나오고, 칸마다 `open` 시각에 열립니다.
- 화면마다 위쪽 항목 단추를 누르면 그 항목만 보입니다(예: 준비물 → 챙길 것 / 두고 올 것 / 알릴 것 / 모이는 시간).
- 미리 보기: 주소 끝에 `?now=2026-11-19T13:40`처럼 붙이면 그 시각의 화면을 볼 수 있습니다. 로컬에서는 `python3 tools/serve.py`.
- 학교 이름, 선생님 전화번호, 학생 이름은 넣지 않습니다. 검색 노출은 막아 두었습니다.
- 선생님 앱: https://seoul-nadeuri.web.app/teacher/ (학생 앱 첫 화면 맨 아래 링크). 홈 화면에 따로 추가할 수 있습니다. 선생님 코드로 열고, 인원 체크(학년별·조별·방별)와 학생이 쓴 계획서·활동지 보기를 합니다.
- 학생은 학번으로 로그인해요(처음 한 번은 학생 코드도). 점심, 계획서, 활동지가 그 이름으로 저장되고, 앱을 껐다 켜거나 다른 휴대전화에서 로그인해도 서버에서 불러와 이어서 고칠 수 있어요.
- 로그인한 학생의 계획서와 활동지가 암호문으로 Firestore에 올라가 선생님 앱에 보입니다. Firebase 콘솔에서 Firestore를 켜고 `firestore.rules` 내용을 규칙에 게시해야 합니다.
- 학생 명단은 코드로 잠가 두었습니다. 명단·방 배정이 바뀌면 잠금 블록(`TEAMS_SEALED`, `TEACH_SEALED`)을 같은 코드로 다시 만들어 넣습니다.
